# 🚴‍♂️ Master Specification: The Delivery Driver Agent Tools

This document outlines the complete persona, communication rules, categories, and **8 Final Production LLM Tool Specifications** for the **Delivery Driver Agent** in Homaatri.

---

## 🎭 1. Persona & Communication Rules
* **Human Persona**: Fast-paced, concise, practical, and location-aware. Speaks in clear, short WhatsApp updates for delivery drivers on the road.
* **Core Rule**: Admin handles driver onboarding in DB. Deliveries are made to Apartment Security Gates (no doorstep flat delivery). Uses GCP Route Optimization API for single-leg navigation (`Stop N ➔ Stop N+1`), uses `driver_phone` for 100% WhatsApp alignment, and relies on practical stop-based status buttons (continuous live location streaming removed as impractical).

### 📍 CATEGORY 1: Driver Profile Lookup

#### Tool 1: `get_driver_profile_tool`
* **Action Source**: Action 1 (`get_driver_profile`)
* **Purpose**: Identifies an onboarded delivery driver when they send a message on WhatsApp.
* **Inputs**:
  - `driver_phone`: `str` (Required, E.164 format e.g. `"+919988776655"`)
* **Expected Output Structure**:
  ```json
  {
    "driver_phone": "+919988776655",
    "driver_name": "Vikram",
    "vehicle_info": "Hero Splendor (TS 09 EQ 1234)",
    "active_status": true,
    "current_assigned_route_id": "rt_801"
  }
  ```
* **DB Read**: `SELECT * FROM driver_profiles WHERE phone_number = ?` (Read)

---

### 🗺️ CATEGORY 3: Sequential Leg Navigation

#### Tool 2: `get_assigned_route_itinerary_tool`
* **Action Source**: Action 3 (`get_assigned_route_itinerary`)
* **Purpose**: Answers driver's query (*"Show my delivery route for Lunch today"*). Returns the full stop sequence generated by GCP Route Optimization API.
* **Inputs**:
  - `driver_phone`: `str` (Required)
  - `meal_window`: `str` (Required, `'LUNCH'` or `'DINNER'`)
  - `date`: `str` (Required, `'YYYY-MM-DD'`)
* **Expected Output Structure**:
  ```json
  {
    "driver_phone": "+919988776655",
    "route_id": "rt_801",
    "meal_window": "LUNCH",
    "total_stops": 6,
    "stops": [
      { "stop_index": 1, "type": "PICKUP_KITCHEN", "location_name": "Ramesh Kitchen", "orders": ["ord_101", "ord_104"] },
      { "stop_index": 2, "type": "DROPOFF_GATE", "location_name": "My Home Bhooja Gate", "orders": ["ord_101", "ord_104"] }
    ]
  }
  ```
* **DB Read**: Global Read on `system_delivery_routes` & `system_delivery_stops`. (Read)

---

#### Tool 3: `dispatch_next_leg_navigation_link_tool`
* **Action Source**: Action 4 (`dispatch_next_leg_navigation_link`)
* **Purpose**: Generates and sends a single-leg Google Maps navigation link for the **VERY NEXT STOP (`Stop N ➔ Stop N+1`)** on WhatsApp.
* **Inputs**:
  - `driver_phone`: `str` (Required)
  - `current_stop_index`: `int` (Required)
* **Expected Output Structure**:
  ```json
  {
    "next_stop_index": 2,
    "stop_type": "DROPOFF_GATE",
    "location_name": "My Home Bhooja Security Gate",
    "orders_to_deliver": ["ord_101", "ord_104"],
    "single_leg_google_maps_url": "https://maps.google.com/?saddr=17.448,78.381&daddr=17.452,78.388",
    "status": "LEG_NAVIGATION_DISPATCHED"
  }
  ```
* **DB Read**: Global Read on `system_delivery_stops`. (Read)

### 🏁 CATEGORY 4: Stop Execution & Delivery Handshakes

#### Tool 4: `mark_driver_reached_stop_tool`
* **Action Source**: Action 5 (`mark_driver_reached_stop`)
* **Purpose**: Triggered when a driver messages *"Reached"* or taps the button `"I Have Arrived"` at a kitchen or security gate stop.
* **Inputs**:
  - `driver_phone`: `str` (Required)
  - `stop_index`: `int` (Required)
* **Expected Output Structure**:
  ```json
  {
    "driver_phone": "+919988776655",
    "stop_index": 1,
    "status": "ARRIVED_AT_STOP",
    "arrived_at": "12:42 PM"
  }
  ```
* **DB Write**: `UPDATE system_delivery_stops SET status = 'ARRIVED'` & `UPDATE driver_trip_status` (Write)

---

#### Tool 5: `mark_orders_picked_up_tool`
* **Action Source**: Action 6 (`mark_orders_picked_up`)
* **Purpose**: Triggered when a driver collects packed food boxes from a home kitchen and taps `"Picked Up Food"`. Updates order status to `PICKED_UP` and dispatches next leg navigation link.
* **Inputs**:
  - `driver_phone`: `str` (Required)
  - `stop_index`: `int` (Required)
  - `order_ids_list`: `list[str]` (Required)
* **Expected Output Structure**:
  ```json
  {
    "stop_index": 1,
    "orders_picked_up": ["ord_101", "ord_104"],
    "status": "FOOD_PICKED_UP",
    "next_leg_navigation_url": "https://maps.google.com/?saddr=17.448,78.381&daddr=17.452,78.388"
  }
  ```
* **DB Write**: `UPDATE customer_orders SET status = 'PICKED_UP'` & `UPDATE driver_trip_status` (Write)

---

#### Tool 6: `mark_gate_delivery_completed_tool`
* **Action Source**: Action 7 (`mark_gate_delivery_completed`)
* **Purpose**: Triggered when a driver drops off multi-order food packages at an Apartment Security Gate (*"Delivered 5 orders to My Home Bhooja Security Guard"*). Updates order status to `DELIVERED` and notifies Master Agent $\rightarrow$ Customer Agent.
* **Inputs**:
  - `driver_phone`: `str` (Required)
  - `stop_index`: `int` (Required)
  - `order_ids_list`: `list[str]` (Required)
  - `left_with_security`: `bool` (Required)
* **Expected Output Structure**:
  ```json
  {
    "stop_index": 2,
    "orders_delivered": ["ord_101", "ord_104"],
    "left_with_security": true,
    "status": "GATE_DELIVERY_COMPLETED",
    "customers_notified": true
  }
  ```
* **DB Write**: `UPDATE customer_orders SET status = 'DELIVERED'` & `UPDATE system_delivery_stops` (Write)

---

### 🤝 CATEGORY 5: HITL & Exception Management

#### Tool 7: `report_unlocatable_address_hitl_tool`
* **Action Source**: Action 8 (`report_unlocatable_address_hitl`)
* **Purpose**: Triggered when a driver reports *"Cannot find gate for Order #104"*. Pauses graph execution via LangGraph `interrupt()` and alerts Master Agent $\rightarrow$ Customer Agent to request an updated location pin on WhatsApp.
* **Inputs**:
  - `driver_phone`: `str` (Required)
  - `stop_index`: `int` (Required)
  - `order_id`: `str` (Required)
* **Expected Output Structure**:
  ```json
  {
    "order_id": "ord_104",
    "stop_index": 2,
    "hitl_status": "INTERRUPTED_WAITING_CUSTOMER_LOCATION_PIN",
    "master_agent_notified": true,
    "status_message": "Customer requested for location pin update on WhatsApp."
  }
  ```
* **DB Write**: Saves checkpoint to LangGraph State Checkpointer.

---

#### Tool 8: `report_vehicle_delay_alert_tool`
* **Action Source**: Action 9 (`report_vehicle_delay_alert`)
* **Purpose**: Triggered when a driver reports traffic or vehicle breakdown (*"Stuck in traffic for 15 mins"*). Recalculates ETAs for remaining stops and alerts Master Agent $\rightarrow$ Customers on WhatsApp.
* **Inputs**:
  - `driver_phone`: `str` (Required)
  - `delay_minutes`: `int` (Required)
  - `delay_reason`: `str` (Required)
* **Expected Output Structure**:
  ```json
  {
    "driver_phone": "+919988776655",
    "delay_minutes": 15,
    "reason": "Heavy traffic on Hitech City Flyover",
    "status": "ETA_UPDATED_AND_CUSTOMERS_NOTIFIED"
  }
  ```
* **DB Write**: `UPDATE system_delivery_stops SET estimated_arrival = ...` (Write)
