Architecture & Build Sequence Blueprint

Homaatri Action Dependency & Tool Build Map

A complete visual mapping of cross-agent dependencies determining the exact 4-tier logical build sequence for Homaatri's AI tools.

Logical Tool Build Order

01
Phase 1 (Foundation)

Chef Domain & Master Cutoff Engine

Data Provider Foundation. Chefs, menus, & daily capacities must exist before customers can browse or order.

02
Phase 2 (Ingestion)

Customer Agent & Payment Gateway

Depends on Chef Menus & Master Cutoff Clock. Enables location discovery, cart checkout, and payment links.

03
Phase 3 (Orchestration)

Master Route Solver & Chef Packing

Runs at 12 PM / 7 PM cutoff. Locks batch, calls GCP Route Optimization, dispatches chef checklists & packing signals.

04
Phase 4 (Fulfillment)

Driver Agent & Cross-Domain Relays

Reads Master Route itinerary. Feeds leg-by-leg navigation links, stop handshakes, and gate delivery alerts.

Detailed Action Dependencies by Phase

Phase 1: Foundation (Chefs & Master Clock)

BUILD FIRST — ZERO DEPENDENCIES
validate_meal_window_cutoff_clock Master
Rejects Lunch orders after 12:00 PM and Dinner orders after 7:00 PM.
➔ Required By: Customer.create_customer_order
set_daily_batch_capacity Chef
Sets max meal prep limit per dish for a date (e.g. max 15 Thalis).
➔ Required By: Customer.view_chefs_sorted_by_distance
➔ Required By: Customer.add_item_to_order
toggle_dish_stock_status Chef
Marks dish IN_STOCK / OUT_OF_STOCK mid-day when ingredients run out.
➔ Required By: Customer.view_chef_menu

Phase 2: Ingestion & Checkout (Customer Agent)

BUILD SECOND — DEPENDS ON PHASE 1
view_chefs_sorted_by_distance Customer
Calculates distance (Haversine math) and ranks active home kitchens closest to customer.
⬅ Depends On: Chef.chef_profiles, Chef.set_daily_batch_capacity
create_customer_order Customer
Validates cutoff clock and initializes order header in DB.
⬅ Depends On: Master.validate_meal_window_cutoff_clock
➔ Required By: Chef.get_chef_batch_checklist, Master.orchestrate_gcp_route_optimization
generate_initial_payment_link Customer
Programmatically calculates final total and generates UPI payment link.
⬅ Depends On: Customer.add_item_to_order
➔ Required By: Master.process_payment_webhook_confirmation

Phase 3: Cutoff Orchestration & Cooking (Master & Chef)

BUILD THIRD — DEPENDS ON PHASE 2
orchestrate_gcp_route_optimization Master
Calls GCP Route Optimization API at cutoff, groups apartment gate drop-offs, and saves master route.
⬅ Depends On: Customer.create_customer_order (Confirmed Orders)
➔ Required By: Driver.get_assigned_route_itinerary
get_chef_batch_checklist Chef
Delivers consolidated order prep checklist to home cooks at 12 PM / 7 PM cutoff.
⬅ Depends On: Master.lock_meal_window_batch, Customer.create_customer_order
mark_order_packed_ready Chef
Broadcasts food packed signal so Master Agent notifies assigned delivery driver.
⬅ Depends On: Customer.create_customer_order
➔ Required By: Master.relay_order_ready_signal_to_driver

Phase 4: Fulfillment & Driver Dispatch (Driver & Relays)

BUILD FOURTH — DEPENDS ON PHASE 3
get_assigned_route_itinerary Driver
Reads master route sequence generated by GCP Route Optimization API.
⬅ Depends On: Master.orchestrate_gcp_route_optimization
dispatch_next_leg_navigation_link Driver
Dispatches single-leg Google Maps link (Stop N ➔ Stop N+1) as driver messages "Reached".
⬅ Depends On: Driver.mark_driver_reached_stop
mark_gate_delivery_completed Driver
Marks multi-order gate drop-off complete and triggers Master Agent to alert customers.
⬅ Depends On: Driver.mark_orders_picked_up
➔ Required By: Master.relay_gate_delivery_completed_to_customer
