What changed (July 2026): there is no longer a Model access page or an "enable specific models" step. Just invoke Claude once (playground or API) and it turns on. If Anthropic requires the use-case form, that prompt appears at first invocation — fill it with the answers in Step 2.

1 Invoke Claude once to trigger enablement

  1. Sign in to the AWS Console as an admin/IAM user with Bedrock access.
  2. Top-right region selector → choose US East (N. Virginia) / us-east-1. (This is where we invoke the models.)
  3. Open Amazon Bedrock → left sidebar → Playgrounds → Chat / Text. Direct link:
    console.aws.amazon.com/bedrock/home?region=us-east-1#/text-generation-playground
  4. Click Select model → Anthropic → pick Claude Haiku 4.5.
  5. Send any test message (e.g. "hello"). If a use-case form appears, go to Step 2. If it just replies, access is already on — skip to Step 4.

3 Submit & wait

  1. Review and Submit the use-case details.
  2. Anthropic approval is usually minutes to a few hours. Once cleared, invoking Claude simply works — no separate "Access granted" page to watch anymore.
  3. Re-try a message in the playground after ~15 minutes to confirm it responds.

4 Flip Homaatri to Claude

Once access is granted, in the project .env replace the two active model lines with:

BEDROCK_MODEL_ID=us.anthropic.claude-haiku-4-5-20251001-v1:0
BEDROCK_FALLBACK_MODEL_ID=us.anthropic.claude-sonnet-4-5-20250929-v1:0

…then restart the server. (These lines are already pre-written as a comment in your .env.) Or just tell me "Claude's approved" and I'll flip it and verify.
