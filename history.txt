   - Implemented strict guardrails:
     * Context Assembler (`app/services/context.py`): Injects system policy, live order state, last-N transcript, vector trio memory, and rolling summary into every LLM turn.
     * Policy Engine (`app/services/policy.py`): Enforces state machine lifecycle rules as tool pre-conditions.
     * System-Authored Financial Integrity: Itemized bills, exact price calculations, and payment links generated programmatically by backend services (LLM never guesses prices or payment URLs). Handling of mid-cooking item additions via incremental top-up payment links.
